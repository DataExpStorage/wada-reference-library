    Summary of Modifications – TD2023LDOC v 1.1

    TD2023LDOC

    Summary of Major Modifications

    The Technical Document (TD) on Laboratory Documentation Packages, TD2023LDOC, has been revised to consistency with the current TD MRPL.

    Main Document

    • In section 3.3.2 Additional Documentation for Non-Threshold Substances with a Minimum Reporting Level (MRL), the details of the MRL adjustment, if the Sample's Specific Gravity (SG) is above 1.018, is removed and replaced with a reference to the TD MRPL for the details of the adjustment calculation.

    The TD2023LDOC version 1.1 replaces the former TD2023LDOC version 1.0 and with the effective date of 1 October 2023, which has been set based on the consideration that version 1.1 has minimal impact on Laboratory operations.
